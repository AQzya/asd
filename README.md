# asd

## Claude skills

- [`skills/roblox-map-design`](skills/roblox-map-design/SKILL.md): a skill that helps Claude
  plan and build Roblox maps (layout, scale rules, Luau generators, lighting, performance,
  Rojo + GitHub workflow).

### Using the skill

Claude Code: copy `skills/roblox-map-design` into `.claude/skills/` of your project
(or `~/.claude/skills/` for all projects).
claude.ai: zip the `roblox-map-design` folder and upload it in Settings under Skills.
